# Sales-Performance-Analysis
Built a sales analytics dashboard in Excel using Data Modeling and Power Pivot. Created DAX-based KPIs and interactive Pivot Tables to deliver data-driven business insights
#### This project focuses on analyzing and modeling sales data using advanced Excel features such as Data Modeling and Power Pivot. The objective was to transform raw sales data into meaningful insights to support data-driven decision-making.
### 🎯 Project Objectives
- Create a **Customer Performance Report** to analyze customer-level sales contribution.
- Conduct a comparison between **Market Performance and Sales Targets**.

### 💡 Purpose of Sales Analytics
- Monitor and evaluate sales performance.
- Track key performance indicators (KPIs).
- Identify sales trends and growth opportunities.

### 📊 Business Value
- Supports data-driven decision-making.
- Helps optimize customer discount strategies.
- Identifies high-potential markets for expansion.

## 💰 Finance Report

### 🎯 Project Objectives
